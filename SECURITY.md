# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Earshot, please report it privately rather than opening a public issue.

**Email:** michael@payown.media

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Any suggested mitigation

We'll acknowledge receipt within 72 hours and aim to provide an initial assessment within 7 days.

## Supported versions

Once Earshot has a v1 release, we support the latest released version of the iOS and Android app. Older versions do not receive security updates.

## Disclosure

We follow coordinated disclosure. Once a fix is available, we'll work with you on timing for public disclosure.

## Scope

In scope:
- Vulnerabilities in the Earshot mobile app (iOS and Android)
- Vulnerabilities in the Earshot Cloud backend (once it exists in v1.1)
- Privacy leaks (data sent off-device that shouldn't be)

Out of scope:
- Vulnerabilities in third-party podcast feeds
- Issues in dependencies (please report to the upstream maintainer)
- Social engineering
