## Build 201 candidate boundary

Build 200 was the first source candidate whose Release configuration enabled the
compact private CloudKit projection. Debug remains local-only. The explicit
CloudKit Development configuration also remains enabled for pre-production
testing. The signing profile selects the development or production CloudKit
environment; both V10 application stores remain configured with CloudKit
database `.none` in every build.

Build 200 was retired after committed Delete Synced Library Everywhere cleared
the Mac library and then deadlocked during replacement-store activation. Build
201 moves the one-time replacement-store initialization ahead of SwiftUI
publication and makes its two keys a single transaction. It also prevents cold
feed refresh from racing remote cascade deletion and cleans invalid orphan rows
left by build 200. Build 201 reopened the preserved failed Mac state without the
deadlock, and the phone then converged to a completely empty, integrity-clean
library without issuing Delete a second time. The targeted settings, reset-race,
projection, and orphan-cleanup regressions pass. The final full build-201 run
passed 1,808 tests with 26 documented skips and zero failures, and the signed
1.1.0 (201) replacement Release archive passed strict signature verification.
Michael confirmed the physical iPhone Library was fully empty after convergence.

Build 202 incorporates the two final tester-feedback fixes accepted on device:
the iOS 26 mini player uses the native persistent tab accessory so VoiceOver
Explore by Touch finds it above the tab bar, and podcast episode ordering is a
single reversible oldest/newest toggle that never starts playback. Chapter 63
in `docs/kashe.md` is the TestFlight story and test matrix for this build.

Michael confirmed the reviewed compact schema was deployed from Development to
Production on 2026-08-15. Build 202 must be uploaded to both Internal and Public
TestFlight groups; production two-device evidence remains required before App
Review submission.

The exact regenerated build-202 source passed 1,833 simulator tests with 26
documented skips and zero failures. Its App Store Connect export passed strict
signature verification and contains version 1.1.0 (202), production APS,
Production CloudKit, private container `iCloud.media.payown.earshot`, CloudKit

## Stop conditions

Do not submit 1.1.0 if any test requires reinstalling, deleting a library, waiting without a bounded result, silently merging iCloud accounts, accepting missing user data, or explaining away reproducible heat or VoiceOver unresponsiveness. Fix the defect, build a new candidate, and rerun the affected gate plus the release regression set.
