# Earshot 1.1.0 iCloud release gate

Status: blocking  
Owner: @payown  
Tracking issue: #817  

Earshot 1.1.0 must not be submitted to App Review until private iCloud sync is
working in the production CloudKit environment and every required gate below is
recorded with exact evidence. A green build alone is not release approval.

## Required before production deployment

- Approve the compact relationship-free projection as the permanent production record shape (#811).
- Pass the remaining development two-device convergence, conflict, offline/restart, account, heat, and VoiceOver checks (#813–#816, #820).
- Resolve or explicitly disposition every open sync correctness bug, including #819, #821, #824, and #825.
- Confirm local downloads, purchase entitlement records, migration backups, and device-only preferences never mirror.
- Retain a recoverable pre-deployment snapshot and verify SQLite integrity on both test devices.

## Required before App Review

- Review and deploy the additive CloudKit schema to Production.
- Archive the exact 1.1.0 candidate and verify its container identifier, entitlements, capabilities, signing, privacy metadata, and build number.
- Upgrade from the current App Store build without uninstalling or deleting the library.
- Run the complete production two-device matrix in `docs/icloud-sync-device-test.md`, recording timestamps and before/after counts.
- Prove offline launch, offline mutation durability across restart, reconnect propagation, background/foreground delivery, and force-quit recovery.
- Prove stale progress cannot rewind active playback and an explicit rewind does synchronize.
- Exercise signed-out, restricted, temporarily unavailable, account-change, quota/server failure, Clear This Device, and Delete Synced Library Everywhere behavior.
- Run controlled 30-minute playback samples at 1x, 1.5x, and 2x with VoiceOver, recording battery, thermal state, CPU, memory, sync traffic, downloads, and spoken responsiveness.
- Confirm iCloud Settings reports `Syncing` for current work and an honest `Last completed on this device` value without routine speech or focus theft.
- Pass the full non-StoreKit test suite, GitHub Actions, a signed Release build, migration/reset/OPML/Bluetooth/playback/purchase regressions, and physical VoiceOver checks on iPhone and Designed-for-iPhone Mac.

## Stop conditions

Do not submit 1.1.0 if any test requires reinstalling, deleting a library, waiting without a bounded result, silently merging iCloud accounts, accepting missing user data, or explaining away reproducible heat or VoiceOver unresponsiveness. Fix the defect, build a new candidate, and rerun the affected gate plus the release regression set.
