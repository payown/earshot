# Earshot 1.2.0 release notes

Candidate: version 1.2.0, build 252.

## App Store “What’s New” copy

Earshot 1.2 adds powerful new ways to discover, organize, and listen to
podcasts—while making VoiceOver navigation faster and more responsive.

- Browse Apple Podcasts categories and explore complete episode catalogs
  without following a show.
- Search and filter episodes within a podcast by title, duration, or custom
  patterns.
- Save Queue lineups, group queued episodes by folder, and control large
  download jobs.
- View and export improved transcripts with optional speakers and timestamps.
- Use Siri and Shortcuts to skip forward or backward.
- Customize exactly what VoiceOver speaks for episode and podcast rows.
- Continue interrupted OPML imports without selecting the file again.
- Recover corrected or broken podcast audio with Refresh Episode Audio.
- Optionally write listening progress to an open Listening Places file in a
  folder you choose.

This update also improves feed refresh visibility, playback controls, download
notifications, iCloud reliability, background performance, and responsiveness
across large libraries. It includes extensive crash prevention and stability
work throughout Earshot.

## Release details

- Listening Places writes this device's state only in version 1.2.0. Reading
  another device's changes is planned for a later update.
- No new data is collected.
- No new CloudKit record type or production schema deployment is required.
- VoiceOver speech preferences remain local to each device.
- Version 1.2.0 supports the same iOS 18 minimum as version 1.1.0.
