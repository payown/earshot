# Earshot 1.2.4 release notes

Candidate: version 1.2.4, build 274. App Store review submission is pending
physical-device verification and an uploaded, processed build.

## App Store “What’s New” copy

Add audio files from Files to the new Personal Audio section in Library. Earshot saves your place and remembers a playback speed for each file. This update also expands Siri and Shortcuts playback actions, lets you share episode links, adds podcast search and sorting options, and offers an optional Home Screen badge for downloaded unheard episodes. Launch, Library, Queue, and folder picker responsiveness have improved. Personal Audio import and reset cleanup are more reliable.

## Before submission

- Verify VoiceOver cold-launch responsiveness and per-file Personal Audio speed on a physical device using this exact build.
- Verify existing Library, downloads, Queue, and Personal Audio remain intact after installing over TestFlight 1.2.3 (273).
- Confirm App Store Connect version 1.2.4 has the processed build 274 attached and passes submission validation.
- Keep manual release selected so approval does not publish automatically.
