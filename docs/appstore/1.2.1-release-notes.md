# Earshot 1.2.1 release notes

Candidate: version 1.2.1, build 255.

## App Store “What’s New” copy

Discover podcast search is now faster and more reliable, especially when using
VoiceOver. This update prevents Earshot from becoming unresponsive as search
results load and improves the responsiveness of typing, navigation, podcast
descriptions, and artwork loading.

## Release details

- No new data is collected.
- No new CloudKit record type or production schema deployment is required.
- VoiceOver labels, values, actions, and focus behavior are unchanged.
- Version 1.2.1 supports the same iOS 18 minimum as version 1.2.0.
