# Earshot 1.1.1 release notes

Candidate: version 1.1.1, build 211.

## Recommended App Store “What’s New” copy

This update gives VoiceOver listeners more control over what Earshot speaks and makes large OPML imports easier to finish.

- Continue an OPML import after reaching the free-plan limit without choosing the file again. A verified Earshot Plus purchase or restore resumes the saved import, and pending work can be continued or discarded in Settings.
- Choose whether episode rows speak the podcast name, published date, download or streaming status, and duration or time remaining.
- Set episode and Library podcast descriptions to Off, Brief, or Full. Brief descriptions are on by default and sanitized so VoiceOver never reads raw markup.
- Hear the same configured episode details in Inbox, Queue, Downloads, folders, search, podcast episode lists, and multi-select mode.

This update also preserves imported folder assignments, prevents duplicate subscriptions during continuation, keeps speech preferences local to each device, and includes stability and performance safeguards for large libraries.

## Privacy and compatibility

- No new data is collected.
- No new CloudKit record type or production schema deployment is required.
- VoiceOver speech preferences remain local to each device.
- Version 1.1.1 supports the same iOS 18 minimum as version 1.1.0.
